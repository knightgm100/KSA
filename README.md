# أطلس المملكة

تجربة تفاعلية RTL تستعرض تاريخ المملكة العربية السعودية باستخدام Three.js وGSAP ScrollTrigger.

## التشغيل

لا توجد تبعيات محلية مطلوبة. افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً من هذا المجلد:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

المكتبات محملة عبر CDN:

- Three.js لرسم الكرة الأرضية والمؤشر الجغرافي.
- GSAP وScrollTrigger لحركة الـHero والخط الزمني.
